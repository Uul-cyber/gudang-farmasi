Konfirmasi Import

Data lama tetap aman

Import akan MENAMBAH data baru dari file Excel. Data lama tidak akan dihapus.

Aturan Import:

  • Obat sudah ada (nama sama) → di-skip
  • Obat baru → ditambahkan ke Master Obat
  • Rak sudah ada → dipakai ulang
  • Rak baru → dibuat otomatis
  • Batch sudah ada → di-skip
  • No Batch kosong / angka urut → auto-generate

Data lama aman. Import bisa dijalankan berkali-kali tanpa duplikat.
